🌤️ Project 04: Live Weather Dashboard

📌 About the Project

The Live Weather Dashboard is a responsive web application developed as part of the InternCircle Internship Program.

This application allows users to search for any city and view its current weather information and five-day weather forecast.

It uses the Open-Meteo Geocoding API to find city coordinates and the Open-Meteo Weather Forecast API to fetch real-time weather data.

🎯 Features

- Search weather by city name.
- Display city name and country.
- Show current temperature.
- Display weather conditions with icons.
- Show humidity percentage.
- Display wind speed.
- Show feels-like temperature.
- Display a five-day weather forecast.
- Show maximum and minimum temperatures.
- Automatic weather loading for Kolkata.
- Search by clicking the Search button.
- Search by pressing the Enter key.
- Error handling for invalid city names.
- Responsive design for mobile and desktop devices.
- Attractive gradient background and weather cards.

🛠️ Technologies Used

- HTML5 – For creating the webpage structure.
- CSS3 – For styling and responsive design.
- JavaScript – For adding interactive functionality.
- Fetch API – For requesting data from external APIs.
- Async/Await – For handling asynchronous operations.
- JSON – For processing API response data.
- Open-Meteo API – For fetching weather information.

🌐 APIs Used

1. Open-Meteo Geocoding API

Used to search for a city and retrieve its latitude and longitude.

API: https://geocoding-api.open-meteo.com/v1/search

2. Open-Meteo Weather Forecast API

Used to fetch current weather information and five-day weather forecasts.

API: https://api.open-meteo.com/v1/forecast

Note: Open-Meteo provides free API access without requiring an API key for this project.

🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the "weather.html" file.
4. Right-click and select Open with Live Server.
5. The Weather Dashboard will open in your browser.
6. Enter a city name in the search box.
7. Click Search to view current weather and the five-day forecast.
